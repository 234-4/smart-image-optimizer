Questions, answered.

Are my images uploaded?

No. Processing uses your browser's File and Canvas APIs. The app does not send image data to a server.

Can I compress to an exact size?

The optimizer searches quality and dimensions to get close. Image encoders cannot guarantee an exact byte count, so the result reports what it achieved.

Will transparency be preserved?

Auto mode keeps PNG when transparency is detected. JPG cannot store transparency, so choose WebP or PNG for those images.
