Privacy, without the fine print.

OptmizeImage is designed to process images locally in your browser. The image file you select is read by browser APIs and is not uploaded to our server by the application.

Local processing

Compression, resizing, format conversion and the measurable SEO checks run on your device using JavaScript, File, Image and Canvas APIs. Closing the page clears the working image references.

Storage and analytics

We do not store uploaded image data. This static implementation does not include advertising or third-party analytics. The browser may cache application files for offline use. Preferences are not persisted by default.

Remote websites

OptmizeImage does not fetch or crawl websites. Browser security rules such as CORS make that unreliable without a server, so website analysis should be done by uploading the images you have permission to inspect.
