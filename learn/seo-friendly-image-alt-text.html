How to Write SEO-Friendly Image Alt Text

Good alt text describes the image's purpose for people who cannot see it. Write for clarity first; relevant search context follows naturally.

Describe what matters

Write a short, specific description that communicates the image's meaning in its surrounding content. â€œRed hiking backpack beside a trail mapâ€ is more useful than â€œimageâ€ or â€œbackpack photo.â€

Use context, not keyword stuffing

Alt text is not a place to list search terms. Include a keyword only when it accurately describes the image and helps explain the page. Repeating a phrase can make the text awkward for screen-reader users and does not create useful relevance.

Match the image's role

  • Product: name the product and an important visible feature.
  • Editorial: describe the event, people or action relevant to the story.
  • Chart: summarize the takeaway, and provide the full data in nearby text.
  • Link image: describe the destination or action.
  • Decorative image: use an empty alt attribute, `alt=""`, so assistive technology skips it.

Alt text and captions are different

A caption is visible to everyone and can add attribution or editorial detail. Alt text is an equivalent for the image when it is unavailable. They can overlap, but they should not blindly repeat each other.
